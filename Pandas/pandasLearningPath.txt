EDA CHEATSHEET - CATEGORIZED (pandas + matplotlib/seaborn + stats)
===================================================================

Setup
-----
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats


1) DATA LOADING & INSPECTION
----------------------------
a) Load
   pd.read_csv()
   pd.read_excel()
b) Preview
   df.head()
   df.tail()
   df.sample()
c) Structure
   df.shape
   df.columns
   df.dtypes
   df.info()
   df.memory_usage()
d) Quick look at values
   df.describe()
   df.describe(include="object")
   df.nunique()
   df["column"].unique()
   df["column"].value_counts()


2) SELECTING & FILTERING
------------------------
a) Columns
   df["column"]
   df[["col1", "col2"]]
   df.filter()
   df.select_dtypes()
b) Rows
   df.loc[]
   df.iloc[]
   df.query()
c) Conditional
   df.where()
   df.mask()
   df["column"].isin()
   df["column"].between(a, b)


3) DATA CLEANING
----------------
a) Missing values
   df.isnull()
   df.isna()
   df.notnull()
   df.notna()
   df.isnull().sum()
   df.dropna()
   df.fillna()
   df.ffill()
   df.bfill()
   df.interpolate()
b) Duplicates
   df.duplicated()
   df.duplicated().sum()
   df.drop_duplicates()
   df.drop_duplicates(subset=[])
c) Data types
   df.astype()
   pd.to_numeric()
   pd.to_datetime()
   pd.to_timedelta()
   df.convert_dtypes()
d) Strings
   df["column"].str.strip()
   df["column"].str.lower()
   df["column"].str.upper()
   df["column"].str.title()
   df["column"].str.capitalize()
   df["column"].str.replace()
   df["column"].str.split()
   df["column"].str.contains()
   df["column"].str.startswith()
   df["column"].str.endswith()
   df["column"].str.len()
   df["column"].str.extract()
   df["column"].str.fullmatch()
e) Replace & standardize
   df.replace()
   df["column"].map()
   df.rename()
   df.rename_axis()
   df.set_axis()


4) OUTLIER DETECTION
--------------------
a) Numbers
   df["column"].quantile([0.25, 0.75])      (Q1, Q3 for the IQR rule)
   IQR = Q3 - Q1                            (outside Q1 - 1.5*IQR / Q3 + 1.5*IQR)
   z = (s - s.mean()) / s.std()             (flag where abs(z) > 3)
   df.nlargest()
   df.nsmallest()
   df.abs()
b) Plots
   sns.boxplot(x=df["column"])
   sns.boxplot(data=df, x="cat", y="num")
c) Handling
   df.clip(lower, upper)                    (cap values)
   df.drop()                                (remove rows)
   df.loc[mask, "column"] = value           (replace values)


5) UNIVARIATE ANALYSIS (one column at a time)
---------------------------------------------
a) Numeric summary
   df["column"].mean()
   df["column"].median()
   df["column"].mode()
   df["column"].std()
   df["column"].var()
   df["column"].skew()
   df["column"].kurt()

b) Numeric plots
   sns.histplot(df["column"], kde=True)
   sns.kdeplot(df["column"])
   sns.boxplot(x=df["column"])
   df.hist()
c) Categorical summary
   df["column"].value_counts()
   df["column"].value_counts(normalize=True)
d) Categorical plots
   sns.countplot(data=df, x="column")
   df["column"].value_counts().plot.bar()
   df["column"].value_counts().plot.pie()


6) BIVARIATE ANALYSIS (two columns)
-----------------------------------
a) Numeric vs numeric
   df.corr(numeric_only=True)
   df.cov()
   df.corrwith()
   sns.scatterplot(data=df, x="a", y="b")
   sns.regplot(data=df, x="a", y="b")
b) Category vs numeric
   df.groupby("cat")["num"].mean()
   sns.boxplot(data=df, x="cat", y="num")
   sns.violinplot(data=df, x="cat", y="num")
   sns.barplot(data=df, x="cat", y="num")
c) Category vs category
   pd.crosstab(df["a"], df["b"])
   pd.crosstab(df["a"], df["b"], normalize="index")
   sns.countplot(data=df, x="a", hue="b")


7) MULTIVARIATE ANALYSIS (many columns)
---------------------------------------
a) Correlation
   sns.heatmap(df.corr(numeric_only=True), annot=True)
b) Pairwise
   sns.pairplot(df)
   sns.pairplot(df, hue="target")
c) Summary tables
   df.pivot_table()
   df.groupby([]).agg()
d) Dimensionality reduction (for visualization)
   PCA().fit_transform()                    (sklearn.decomposition)
   TSNE().fit_transform()                   (sklearn.manifold)


8) DISTRIBUTION & STATISTICAL TESTS
-----------------------------------
a) Normality
   stats.shapiro()
   stats.probplot(s, plot=plt)              (Q-Q plot)
b) Group comparison
   stats.ttest_ind()                        (two group means)
   stats.f_oneway()                         (three or more group means)
   stats.mannwhitneyu()                     (non-normal alternative)
c) Category relationships
   stats.chi2_contingency()
d) Numeric relationships
   stats.pearsonr()
   stats.spearmanr()


9) TRANSFORMATION & FEATURE ENGINEERING
---------------------------------------
a) Apply functions
   df.apply()
   df.map()
   df.transform()
   df.pipe()
   df.eval()
   df.assign()
   (Note: applymap() is deprecated; use DataFrame.map())
b) Fix skew
   np.log1p()
   np.sqrt()
   stats.boxcox()
c) Scaling
   StandardScaler().fit_transform()         (sklearn.preprocessing)
   MinMaxScaler().fit_transform()
d) Binning
   pd.cut()
   pd.qcut()
e) Categorical encoding
   pd.get_dummies()
   df.astype("category")
   df["column"].cat.codes
   df["column"].cat.categories
   LabelEncoder().fit_transform()           (sklearn.preprocessing)


10) SORTING, INDEXING & RESHAPING
---------------------------------
a) Sort

   df.sort_index()
b) Index control
   df.set_index()
   df.reset_index()
   df.reindex()
c) Add or remove
   df.drop()
   df.drop(columns=[])
   df.pop()

d) Reshape
   df.T

13) DATE & TIME PROCESSING
--------------------------

   df["date"].dt.quarter

14) TARGET ANALYSIS (for ML)
----------------------------
a) Target distribution

   sns.countplot(data=df, x="target")

c) Features vs target
   df.corrwith(df["target"])
   df.groupby("target").mean(numeric_only=True)
   sns.boxplot(data=df, x="target", y="num")

TYPICAL EDA ORDER
=================
Load (1) -> inspect (1) -> clean (3) -> outliers (4) -> univariate (5)
-> bivariate (6) -> multivariate (7) -> distributions/tests (8)
-> features (9) -> target analysis (14)


NOTES
=====
- read_csv is pd.read_csv(), not df.read_csv().
- between() and isin() are Series methods: df["col"].between(a, b).
- size is an attribute: df.size, or groupby(...).size().
- Replace "column", "col1", "col2", "cat", "num", "date" with real
  column names.
- Choose cleaning strategies based on what the data means; don't
  automatically delete every outlier or fill every missing value.
- Skewness near 0 is symmetric; positive means a long right tail,
  negative a long left tail.
- Fit scalers and encoders on training data only when you move on to
  modeling, to avoid data leakage.
- Sections 4 to 8, 14 and 15 are new compared with the original pandas
  cheatsheet. Sections 1 to 3 and 9 to 13, 16 are the original content,
  reordered.
